BUILD THE APK (no Android Studio needed)
1. Create a free GitHub account and a new empty repository.
2. Upload everything in this folder (including the hidden .github folder) to it.
3. Open the Actions tab -> "Build APK" -> Run workflow (it also runs on every upload).
4. After ~5 minutes open the finished run and download "snake-apk" under Artifacts.
5. Unzip it, send app-debug.apk to your phone and install it
   (allow "install unknown apps" when Android asks).
